## PROJECT OVERVIEW

Sinister-OS is a minimalist operating system built from scratch as an educational
project. It demonstrates fundamental OS concepts including boot sequences, 
kernel operations, and basic device drivers.

## SYSTEM ARCHITECTURE

- Boot Sector: Implements a 2-stage bootloader
- Kernel: 32-bit protected mode kernel
- Drivers: Basic hardware interface implementations

## FEATURES

1. 32-bit protected mode operation
2. Custom bootloader
3. Basic keyboard driver
4. Text-mode display driver
5. Memory management foundations
6. Interrupt handling
7. System resource monitoring

## BUILD INSTRUCTIONS

### Linux/Unix:
- Build full system: `make all`
- Run in QEMU: `make run`
- Clean build artifacts: `make clean`
- Debug with GDB: `make debug`

### Windows:
- Build full system: `make win-os-image`
- Run in QEMU: `make win-run`
- Clean build artifacts: `make win-clean`
- Debug with GDB: `make win-debug`

## AVAILABLE COMMANDS

The OS is currently in early development stages. Available commands include:

- `help` - Display available commands
- `clear` - Clear the screen
- `shutdown` - Shut down the system
- `monitor` - Display system resource usage (CPU, memory, disk)
- `version` - Display system version information (neofetch-like)
- `reboot` - Restart the system
- `uptime` - Show system uptime
- `echo [text]` - Display the text after the command
- `ls` - List contents of the current directory
- `cd [path]` - Change current directory
- `pwd` - Print current working directory
- `cat [file]` - Display contents of a file
- `touch [file]` - Create a new file or update timestamp

## FILESYSTEM

SinisterOS includes a basic FAT-like filesystem with support for:
- Directory structure with paths
- File and directory listings
- Directory navigation
- File metadata (name, size, attributes)
- File operations (view, create)

Currently supported file operations:
- List directory contents (`ls`)
- Change directory (`cd`)
- View current directory path (`pwd`)
- Display file contents (`cat`)
- Create or update files (`touch`)

Special paths:
- `/` - Root directory
- `.` - Current directory
- `..` - Parent directory

## SYSTEM MONITORING

The resource monitor displays:
- CPU usage percentage with visual graph
- Memory usage (used/total) with visual graph
- Disk usage (used/total) with visual graph
- System uptime
- Active process information

## DEBUGGING

To debug the system:
1. Start with debug target: `make debug` or `make win-debug`
2. In another terminal: `gdb`
3. In GDB: `target remote localhost:1234`
4. Set breakpoints and debug as needed

## KEYBOARD SUPPORT

SinisterOS now includes full QWERTY keyboard support with:
- Lowercase and uppercase letters (via Shift or Caps Lock)
- Number keys (0-9)
- Special characters and symbols
- Modifier keys (Shift, Caps Lock)

The following keyboard features are implemented:
1. Case sensitivity with Shift and Caps Lock
2. Number row with symbols accessible via Shift
3. Full set of punctuation and special characters
